## Title

Avenrow Kitchen — Responsive React Restaurant Website

## Role

Frontend Developer — self-directed visual implementation

## Description

Avenrow Kitchen is a self-directed fictional restaurant website concept built with React, JavaScript, Vite, Tailwind CSS, React Router, and Vercel.

I implemented a responsive multi-page experience with editorial restaurant layouts, a canonical 18-item menu with accessible category filtering, keyboard-friendly mobile navigation, and a custom Not Found route. The interface uses responsive WebP image delivery with PNG fallbacks, deliberate loading behavior, and route metadata for portfolio-ready deployment.

The Contact page demonstrates accessible local validation, first-invalid focus, duplicate-submit protection, and a clear simulated success state. It does not send, store, or log messages, which keeps the fictional concept transparent while still demonstrating form interaction work.

This is a portfolio concept, not client work or a live commercial restaurant launch.
